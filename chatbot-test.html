Does the widget load?

This page embeds the external chatbot script and gives it a realistic environment to initialise in. Open the page in a browser and look for the chat button in the bottom-right corner.

Embedded script tag

<script defer src="https://irelandaichat.com/vendor/chatbot/js/external-chatbot.js" data-chatbot-uuid="b471a959-ce14-4280-872e-02078fee92ea" data-iframe-width="420" data-iframe-height="745" data-language="en" ></script>

Look for a floating chat button, typically in the bottom-right corner of the viewport.

UUID bound

The bot identity is tied to b471a959… — check the network tab to confirm the correct bot loads.

What to check

  1. Open this file in a browser (a local server is fine; python -m http.server works).
  2. Open DevTools → Network and filter by the script filename to confirm it downloaded with HTTP 200.
  3. Verify a chat icon appears in the bottom-right corner within a second or two of page load.
  4. Click the icon — the iframe should open at 420 × 745 px and the bot should greet you in English.
  5. Check the Console tab for any JS errors that might indicate a misconfigured UUID or blocked domain.
